# assets/icons — готовые иконки Fluent UI System Icons

Монохромные regular-глифы [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)
(MIT, © Microsoft Corporation), отрендеренные в PNG 16/20/24/32/48 px. Каждый
файл — чёрный `#000000` + альфа; `src/icons.rs` заменяет RGB цветом темы,
поэтому один ассет работает и для обычного, и для акцентного, и для
приглушённого состояния. Filled-варианты не поставляются: они приходят как
`#212121` и на тёмной панели требуют той же перекраски.

| файл | Fluent-глиф | где используется |
|---|---|---|
| `grid-*.png` | Grid | панель, лаунчер |
| `terminal-*.png` | Window Console | панель, терминал |
| `folder-*.png` | Folder | панель, файлы |
| `image-*.png` | Image | панель, Paint |
| `network-wired-*.png` | Plug Connected | панель (20 px) и карточка флайаута «Сети» (24 px) — проводная сеть, не Wi-Fi |
| `window-minimize-*.png` | Subtract | кнопка окна `_` |
| `window-maximize-*.png` | Square | кнопка окна `□` |
| `window-close-*.png` | Dismiss | кнопка окна `×` |

Лицензия: [`LICENSE`](LICENSE) — MIT, Copyright (c) 2020 Microsoft Corporation.
Исходные SVG не входят в репозиторий: PNG подготовлены из официального
набора Fluent; соответствие имён-ключей — `manifest.json` в кэше подготовки
(`schema: pagh-icons/1`, `license: MIT`).

## Как эти PNG получены (и как повторить)

Генератор — [`tools/gen_icons.py`](../../tools/gen_icons.py). Он фиксирует
конвейер, которым сделаны текущие файлы, и пишет рядом
[`manifest.json`](manifest.json): глиф Fluent, нативный размер-мастер и
фазу для каждого файла.

```sh
python3 tools/gen_icons.py --svg-root ~/.cache/pagh-icons/fluent-sparse/assets
```

Три правила, из которых выросло качество:

1. **Вектор рендерится cairosvg сразу в целевой размер** — растр никогда не
   масштабируется. Прежняя сборка брала нативный размер Fluent «ближайший
   снизу» и рендерила ЕГО дизайн в целевой размер: у 36 ассетов это был
   апскейл дизайна (`Window Console` во Fluent есть только в 20 px).
2. **Суперсэмплинг не нужен.** Измерено: 4x→BOX даёт те же пиксели (±0.5 %
   «туши»), 4x→LANCZOS вдвое увеличивает число полупрозрачных пикселей и
   даёт ореол. У cairo точное площадное покрытие уже на целевом размере.
   Флаг `--ss` оставлен для экспериментов.
3. **Фазовая подгонка.** Если сдвиг глифа на полпикселя делает 1 px штрих
   непрозрачным при той же сумме альфы (±5 %), сдвиг применяется: геометрия
   не меняется, штрих просто встаёт на пиксельную сетку. Без этого
   `Subtract` 16/20 приходил серой полосой (max alpha 136), `Dismiss` 16 —
   бледным крестом.

Ограничение набора (не рендера): у `Grid` нет дизайнов 32/48, у `Window
Console` — вообще кроме 20, у `Subtract` — 32. Такие ассеты отрисованы из
ближайшего нативного дизайна вектором: гладко, но штрих чуть тяжелее
нативного. При появлении нативных SVG достаточно повторно запустить
генератор.
